Great Chasms is a minecraft mod for 26.1.2 neoforge that requires compatibility with Tectonic, Regions Unexplored, Streams Reflowing, C2ME, and Lithostitched.



Unlike minecraft's old ravines, where its only like 10-20 blocks deep or depending where it is, they are insanely small. Via Tectonic Config they will be removed permanently.



Great Chasms will recreate ravines making them immensely bigger, and instead of stopping at stone or deepslate, they cross through thousands of blocks in the actual world and reach all the way to bedrock, but without the bedrock. Basically it goes straight into the void.
They will be very wide at max hundreds of blocks. So to cross you either need to "fly" or to create a large bridge to cross through the chasm.

The Great Chasm is also a very good way of getting ores. It also CANNOT allow structures to generate like oil wells from oritech, camps, any structures.



If it generates in oceans, prevent water from going into them, if they pour in from the sides, thats fine.

If need be, use Lithostitched.
